# Rogue Assistant (Linux variant)

This is an unofficial fork of [Rogue Assistant](https://github.com/Pokabbie/pokeemerald-rogue-assistant)
by Pokabbie, the author of Pokemon Emerald Rogue. The fork adds Linux support.
The upstream project is Windows only.

**This fork is not official. Do not report problems with this version to the
original developer.** If you find a problem, use the
[issue tracker](https://github.com/AshmitW/pokeemerald-rogue-assistant/issues)
of this fork.

## Downloads

| Operating system | What you get |
|---|---|
| Windows | This fork does not supply a Windows build. Use the [official release](https://github.com/Pokabbie/pokeemerald-rogue-assistant/releases). |
| Linux | Source code. You must build it. |

To get the source code, use one of these methods:

- Download a release from the [releases page](https://github.com/AshmitW/pokeemerald-rogue-assistant/releases).
- Clone the repository, or download it as a ZIP file.

There is no Linux build in the releases. A Linux program that one distribution
builds usually does not operate on a different distribution, because the
versions of the C library and of SFML are different. The build takes less than
one minute. Refer to [linux/README.md](linux/README.md) for the instructions.

If you have a problem or a question, open an issue on the
[issue tracker](https://github.com/AshmitW/pokeemerald-rogue-assistant/issues).

## Use the official version on Windows

If you use Windows, use the
[official release](https://github.com/Pokabbie/pokeemerald-rogue-assistant/releases).
This fork is only for Linux players.
